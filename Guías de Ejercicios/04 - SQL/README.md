# Guía de Ejercicios - SQL

La práctica de SQL se resuelve de forma interactiva en el navegador (base de datos Northwind sobre SQLite), no como notebook.

Accedé a la guía en: **https://edalef.com**

Temas: SELECT, WHERE, ORDER BY, DISTINCT, LIMIT, GROUP BY, funciones de agregación (COUNT, SUM, MAX, ROUND, COUNT DISTINCT), JOIN de 2-3 tablas, self-join, LEFT JOIN, HAVING y concatenación con `||`.
